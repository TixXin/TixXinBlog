## 产品介绍

TixXinBlog 是面向单个博主的个人博客：公开网站与 `/admin` 后台一体，文章、闪念、朋友圈、留言、图库、项目与友链都存放在自带的 PostgreSQL 中。首次安装后通过浏览器初始化向导创建博主账号，无需命令行。

## 主要功能

- 文章、闪念、朋友圈、留言板、图库、项目与友链，三套可切换主题
- 内置后台：草稿与修订、评论审核、媒体管理、内容包导出与恢复
- 简体中文与英文界面，访客可自行切换
- 访客 IP 限流、Secure Cookie、一次性初始化令牌

## 安装

本应用不自带 HTTPS 入口，由 1Panel「网站」（OpenResty）负责域名与证书。安装前先在 1Panel 应用商店安装 OpenResty，并把域名解析到服务器。

1. 作为本地应用安装时，把 `tixxin-blog` 整个目录上传到 `/opt/1panel/resource/apps/local/`（1Panel 安装在其他目录时相应替换 `/opt`），在「应用商店」点击「同步本地应用」（1Panel v1 为「更新应用列表」）。
2. 安装表单只需填写：
   - **站点域名**：只填域名，例如 `blog.example.com`，不带 `https://` 和路径；
   - **站点语言**：简体中文或 English，访客仍可在界面中切换；
   - **HTTP 端口**：容器只监听 `127.0.0.1` 上的这个端口，外网无法直接访问。
3. 数据库密码、签名密钥与初始化令牌由安装脚本在服务器上随机生成，保存在应用目录 `data/secrets/`，表单里没有这些项。高级设置中的「端口外部访问」无需勾选：编排固定绑定 `127.0.0.1`，勾选也不会对外开放。

## 配置网站与 HTTPS

1. 在 1Panel「网站」创建网站，类型选「反向代理」，主域名填安装时的站点域名，代理地址填 `http://127.0.0.1:<HTTP 端口>`。
2. 在该网站的「HTTPS」中申请或上传证书并启用，开启 HTTP 跳转 HTTPS。站点必须通过 HTTPS 访问：登录 Cookie 带 `Secure`，HTTP 下无法登录。
3. 保留 1Panel 默认的反向代理请求头（`Host`、`X-Forwarded-For`、`X-Forwarded-Proto`），不要改为固定值或删除。应用据此识别访客 IP 和 HTTPS 来源。

OpenResty 以主机网络运行，经 `127.0.0.1` 访问应用端口，应用看到的来源是本应用内部网络的网关。安装脚本为本应用选定一个未占用的私网子网（记录在 `data/network.env`，默认 `172.31.250.0/24`），前端与 API 只信任该子网内的代理，再从 `X-Forwarded-For` 取出 OpenResty 记录的访客地址，访客伪造的 `X-Forwarded-For` 不会生效。站点前面另有 CDN 时，访客地址会是 CDN 节点地址。

## 创建博主账号

网站与证书就绪后，打开初始化链接：

```text
https://<站点域名>/setup?token=<SETUP_TOKEN>
```

链接会打印在 1Panel 安装日志的末尾；令牌也保存在应用目录（「已安装」→ 本应用 →「进入安装目录」）的 `data/secrets/app.env` 中，即 `SETUP_TOKEN=` 后面的值。在页面上设置登录名、密码（12–128 个字符）与站点名称后，跳转到 `/admin/login` 登录。账号创建后向导永久关闭，令牌随即失效。

## 升级与备份

- 每次启动、重建或升级都会先运行 `migration` 服务执行数据库迁移，完成后 API 才启动；已是最新结构时迁移为空操作。迁移成功后该容器保持空闲，属于正常状态。
- **升级时务必勾选「升级前备份应用」**。1Panel 会先停止应用，再打包整个应用目录（数据库文件、媒体与密钥都在 `data/` 下）；升级失败时 1Panel 用该备份自动回滚。迁移会改变数据库结构，回滚到旧版本必须连同数据一起恢复。
- 日常备份使用 1Panel 的应用备份或计划任务「备份应用」；后台「备份」中导出的内容包可另行留存。
- 卸载应用会删除应用目录，包括数据库和媒体，请先备份。
- `data/secrets/` 与 `data/postgres/` 必须一起保留或恢复：数据库密码只在首次初始化时写入，重新生成的密钥无法连接旧数据库，脚本会拒绝这种情况。

## 说明

- 不包含一键安装中的 Caddy 和可选 worker，定时备份与邮件通知请使用 1Panel 计划任务或另行部署。
- 1Panel 网站默认的上传上限为 50 MB；恢复接近 50 MB 的内容包时，在网站配置中适当调大 `client_max_body_size`。
- 可在网站 HTTPS 设置中按需开启 HSTS，建议先用较短有效期观察证书续期。
- 更多配置与运维说明见项目文档：<https://github.com/TixXin/TixXinBlog/tree/main/docs>
