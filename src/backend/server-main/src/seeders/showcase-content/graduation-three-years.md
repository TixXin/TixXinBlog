上周整理抽屉，翻出了 2022 年六月的毕业证封套，里面还夹着第一份 offer 的打印件。三年了。这三年我实习过一家公司，正式工作换了两家，从一个连 Git 冲突都不会解的毕业生，变成了一个能带两三个人做项目的前端。中间有些选择现在看是对的，有些是错的，还有些到今天也说不清。

写这篇不是为了给自己打分，是想趁记忆还清楚，把当时为什么那么选记下来。过几年再回头看，大概会有不一样的理解。

## 实习：选了小公司，学到了“完整”

大四下学期我拿到两个实习 offer，一个是深圳一家几百人的中型互联网公司，一个是南山科技园一家二十来人的创业公司。所有人都劝我去大的，我选了小的。理由很简单：小公司的面试官是技术负责人，聊了一个半小时，最后说“你来了就是前端二号，什么都得做”。我当时觉得“什么都得做”听起来很刺激。

事实证明确实什么都得做。四个月里我写了后台管理系统、小程序、官网，还帮运营配过两次活动页，甚至部署都是我自己在服务器上敲命令。没有人 review 我的代码，出了问题自己查，查不出来就去看源码。那段时间进步非常快，但也养成了一些坏习惯，比如为了赶进度不写测试，比如一个文件写两千行也不拆。

现在回头看，那次选择的得是“见过一个产品从零到上线的全过程”，这个经验在后来面试和做项目规划时都用到了。失是没有人告诉我什么是好的工程实践，我是在第一份正式工作里才补上这一课的，补得有点痛。

## 第一份工作：大团队里的小螺丝

毕业后我没留在那家创业公司，去了福田一家规模更大的公司，前端团队三十多人。原因是想看看“正规军”是怎么干活的。

第一个月我就被 review 打击得够呛。一个两百行的 PR 收到四十多条意见，从变量命名到组件拆分到“这里为什么不写测试”。我一开始很抵触，觉得这些人太较真了，后来发现他们是对的：我在小公司写的那些代码，放在一个三十人维护的仓库里确实会出问题。

那一年我学会了写测试、拆组件、写能让别人看懂的 PR 描述，也第一次知道了设计系统、CI、分支策略这些东西是怎么运作的。这些是实打实的收获。

但大团队也有大团队的问题。我负责的模块很窄，一年下来基本就在做同一个业务线的几个页面，对整个产品的理解反而不如实习时候深。晋升通道看得见但排队的人很多，我的直属领导人很好，但他自己也在等上面的位子。到第二年春天，我开始觉得自己在重复，每天的工作是“做得更熟练”而不是“做得更多”。

> 那段时间我在笔记里写过一句：“我在变成一个很好的零件，但我不想只是零件。”

现在看这句话有点年轻气盛，但当时的焦虑是真的。

## 跳槽：为什么走，以及走对了吗

2024 年四月我换到了现在这家公司，在南山，团队不到十个人，做一个面向海外用户的 SaaS 产品。薪资涨了一些，但不多，真正吸引我的是面试时聊到的两件事：一是前端可以参与产品决策，二是团队在用的技术栈比较新，Nuxt 3 和 TypeScript 全量。

这一年多我确实参与了很多之前接触不到的事。和产品一起定需求优先级，和设计一起定组件规范，还带着两个新人做了一次大的架构重构。上家公司学到的工程实践在这里终于有了用武之地，而且因为团队小，我能把这些实践推成团队的规范，而不只是自己遵守。

但也有代价。小团队意味着没有专门的测试和运维，上线出问题要自己半夜爬起来看。技术上能请教的人变少了，很多东西要自己查自己试。还有一个我换工作前没想到的问题：小公司的业务方向会变，去年底有两个月整个团队在做一个后来被砍掉的功能，那两个月的工作基本归零。

走对了吗？我的答案是走对了，但不是因为现在这家公司更好，而是因为这次换工作让我搞清楚了自己要什么。我要的不是最大的平台或最高的薪水，而是“能对结果负责”的位置。大团队给不了，小团队给得了，代价是不稳定。这个交换我现在愿意做，三十岁以后愿不愿意，不知道。

## 三年里的几个具体教训

**不要在没想清楚之前换工作。**第一次跳槽我是先烦了再找机会的，面试的时候状态不好，拒了两家其实不错的。后来复盘，应该是先想清楚“我要换到什么样的环境”，再去找，而不是先逃离。

**薪资谈判要做功课。**第一份正式工作的薪资我几乎没谈，对方说多少就是多少，后来发现同批入职的人比我高了一截。第二次我提前查了行情，列了自己的产出，最后谈到的数比初始 offer 高了百分之十几。这件事没有人会替你做。

**简历上的项目要能讲三分钟以上。**面试被问“这个项目你具体做了什么”的时候，能讲清楚技术决策和权衡的人，和只能说“我负责了前端开发”的人，面试官的态度完全不同。我现在会在每个项目结束后写一页复盘，不是为了面试，但面试时确实用上了。

**技术栈不是选工作的第一标准。**我第二次换工作有一部分原因是想用更新的技术，这个理由现在看不太站得住。技术栈半年就能学会，团队文化和成长空间才是真正难换的东西。

**保持写东西。**这三年我断断续续写博客，有半年几乎没更新。但回头看，写过的东西比没写的记得清楚得多，而且有几次面试官是看了我的博客才来联系的。

## 接下来

三年是个很短的时间，短到我还没来得及形成什么定型的东西。但有一件事我比较确定：我想继续做能看见结果的事，不管是在哪家公司，用什么技术。

最近也在想要不要往更偏产品或者管理的方向走，但还没想清楚，可能需要再做一两年再说。深圳这座城市每天都有人在换工作、换方向，我不想因为别人在动就跟着动，也不想因为害怕动就一直不动。

把毕业证封套放回抽屉的时候，我顺手把那份 offer 打印件也放了回去。不是因为它多重要，是想着三年后再翻出来看一次，看看那时候的我会怎么评价今天写的这些。
