十月一号，假期第一天，早上七点自然醒。没有闹钟，没有待办，手机放在客厅充电。我在床上躺了十分钟，想的第一件事居然是“博客的搜索功能还有一个 bug 没修”。然后我意识到，这就是过去两年我一直在和它较劲的那个东西：下班之后，脑子关不掉。

这篇不是要给出什么答案，只是把这两年摇摆的过程记下来。写的时候尽量诚实，包括那些现在看起来挺蠢的决定。

## 2024 年秋天：把所有时间都填满

那时候我刚换到现在这家公司，白天做一个还没上线的中台项目，晚上回到南山的出租屋接着写博客，周末接一点外包。记得有一个月，我的 GitHub 提交热力图是全绿的，没有一天空着。朋友问我累不累，我说不累，这是真心话，因为那会儿觉得每一分钟都在产出，这种感觉很上瘾。

转折是十一月的一个周二。外包的客户晚上十点发消息说页面在他的老电脑上打不开，我修到凌晨一点，第二天早上九点的站会上我把一个线上问题的影响范围说错了，同事花了半天去查一个不存在的方向。那天下午我坐在工位上，第一次感觉到“副业在消耗主业”，而主业才是付我房租的那个。

那个月底我把外包全部结掉了。不是因为钱不够用，是因为我发现自己在用“产出”来替代“休息”，而产出这个词在深夜十一点之后的含金量其实很低。

## 2025 年春天：矫枉过正

停掉外包之后，我给自己定了一个规矩，下班之后不开电脑。大概坚持了两个月。那两个月我看了几本书，去了两次大鹏，学会了做三道菜，体重涨了三公斤。

然后开始难受。不是身体上的，是一种说不清的空。有天晚上在华侨城的创意园闲逛，看到一个人坐在咖啡店外面敲代码，屏幕上是我很熟悉的 VS Code 配色，我站在那里看了一会儿，居然有点羡慕。

> 那天回家我在笔记里写：我好像不是讨厌写代码，我是讨厌被人催着写代码。

这句话后来成了我重新调整的起点。问题从来不是“下班之后要不要写代码”，而是“下班之后写的代码是谁的”。给客户写的，是工作的延伸；给自己写的，是生活的一部分。把两者混在一起，才会出现白天上班、晚上也像上班的感觉。

## 2025 年下半年：几条边界

重新开始写博客之后，我慢慢摸出几条边界，到现在还在用。

第一条，只做没有截止日期的事。博客的功能想做就做，不想做就放着，没有人等我交付。一旦某件事有了外部的 deadline，哪怕是我自己答应别人的，它就从生活变成了工作，就该在工作时间做。

第二条，晚上十点之后不写需要思考的东西。可以读文档，可以整理笔记，可以改排版，但不碰逻辑。这条是用好几次凌晨写出的 bug 换来的，十点之后的我，判断力大概只有白天的一半，而第二天早上花二十分钟能做完的事，晚上要花两个小时。

第三条，周末至少有一个整天不碰键盘。这个“不碰”是字面意思，手机可以看，电脑不开。一开始很难，总觉得有什么事没做完，后来发现没做完的事周一也还在，并不会因为我周日看了它就消失。

第四条，和人见面优先于任何代码。朋友约饭、家里来电话、同事喊打球，这些都比博客重要。代码可以明天写，人不一定明天还有空。

这几条不是规则，更像是护栏，偶尔会撞上去，但撞上去的时候知道自己越线了。

还有一条是去年底才加的：钱和兴趣分开算账。博客有一点打赏收入，一年下来大概够付服务器和域名，我一度想过要不要接点广告或者写付费专栏把它做成“副业”。想了很久，最后决定不。一旦它开始挣钱，我就会开始算投入产出，会在意阅读量，会为了更新频率去写自己不想写的东西，那它就又变回工作了。它现在是我花钱养着的爱好，花得起，就这样养着。

## 今年：平衡是动态的

写到这里我想说清楚一点，“平衡”这个词其实有点误导，它让人以为存在一个固定的分配方式，找到就一劳永逸。我的体会是没有。三月份公司项目上线前那三周，我每天回家就睡，博客一个字没写，那时候的平衡就是把所有精力给工作。七月份项目稳定了，我连着两个周末把博客的图库重写了一遍，那时候的平衡就是把精力给自己。

重要的不是比例，是知道自己此刻在哪一边，以及为什么。失控的那段时间，我不是分配得不对，是根本没有在分配，所有事都在抢同一块时间，谁喊得大声谁先来。

顺带说一个具体的变化。以前我的周计划是一张列表，工作、博客、外包、生活混在一起排优先级。现在是两张，一张是工作日的，只放工作；一张是周末和晚上的，只放我自己想做的事，而且第二张允许全空。两张表分开之后，最明显的感受是周日晚上不再焦虑了，因为明天要做的事在另一张表上，今天不用想。

还有一个小发现，和边界有关但不太一样。我后来给博客做了一个“当前状态”的小栏目，就一行字，手动更新。写它的时候得想一下自己最近在做什么，这个动作本身就是一种检查。如果连续两周都是“在改公司的项目”，我就知道该停一停了。

早上躺在床上想到搜索那个 bug 的时候，我最后没有起来修它。起来做了早饭，去楼下的公园走了一圈，回来才打开电脑，花二十分钟修完，然后合上。十月了，深圳终于不那么热，下午打算去海边。bug 会一直有，海边的风不一定。
