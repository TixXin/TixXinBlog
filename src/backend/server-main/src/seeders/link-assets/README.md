# 友链样本标志来源

本目录是 `link-v1` 的必要业务素材，三个标志分别用于指向 Vue.js、TypeScript 和 Vite 官方站点的记录，不用作本站标志，也不声称存在官方合作或已验证互链。下载来源与许可于2026-09-10显式核对；日常种子不抓取用户提交的 URL。

| 文件            | 作者及来源                                                                                                                                                         | 许可 / 品牌说明                                                                                                                        | 实际像素  |
| --------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------ | -------------------------------------------------------------------------------------------------------------------------------------- | --------- |
| vue.webp        | Evan You；[vuejs/art 原 PNG](https://raw.githubusercontent.com/vuejs/art/master/logo.png)                                                                          | [CC BY-NC-SA 4.0 及官方附加许可](https://github.com/vuejs/art#readme)，个人网站及相关开源项目场景；缩放版本遵循同一许可                | 256 × 256 |
| typescript.webp | Microsoft；[TypeScript-Website 原 PNG](https://raw.githubusercontent.com/microsoft/TypeScript-Website/v2/packages/typescriptlang-org/static/icons/ts-logo-512.png) | [CC BY 4.0](https://github.com/microsoft/TypeScript-Website/blob/v2/LICENSE)；[官方品牌说明](https://www.typescriptlang.org/branding/) | 256 × 256 |
| vite.webp       | Vite contributors；[vitejs/vite 原 SVG](https://raw.githubusercontent.com/vitejs/vite/main/docs/public/logo.svg)                                                   | [MIT](https://github.com/vitejs/vite/blob/main/LICENSE)，许可文本同时保留在 `LICENSE-vite.txt`                                         | 256 × 156 |

仅作等比缩放、SVG 栅格化和 WebP 格式转换，未改动标志形状或合成新的图形。种子仍通过媒体上传服务解码，数据库宽高以实际输出为准。

“Vue 中文文档”记录使用相同官方 PNG 的 HTTPS 地址，覆盖外部图片场景；其他没有确认标志的记录保持无图。样本不使用虚构站长头像，不保存探活结果或互链确认标记。运行资源写入显式配置的 `MEDIA_DIRECTORY`，与其他数据集使用独立媒体编号及归属。
