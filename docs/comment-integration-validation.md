# 文章评论联调验收记录

日期：2026-09-06。范围：真实文章与评论 API、游客评论/回复/点赞、错误恢复、按域数据源及回归验证。未提交、推送或部署。

## 最终本地环境

- 前端：http://localhost:3456；文章验收页面：http://localhost:3456/articles/1。
- 后端：http://localhost:3000；接口前缀 `/api/v1`。
- PostgreSQL：复用 `tixxin-blog-postgres` 及原数据卷，无清库、重置或重复 seed。
- 前端 `.env`：`NUXT_PUBLIC_POST_USE_MOCK_REPO=false`、`NUXT_PUBLIC_USE_MOCK_REPO=true`、`NUXT_PUBLIC_API_BASE_URL=http://localhost:3000/api/v1`。
- 文章/评论独立走 HTTP；闪念继续原本地演示路径；标签页明确使用 LocalStorage。
- 配置模板与启动说明位于前后端 README，密钥留在忽略的 `.env.local`，未写入本文或示例配置。

## 改动

- 评论展示组件通过 props/events 协作，传输和状态由 `useArticleComments`、`commentController` 与文章 API 模块管理。
- 支持游客身份、评论、两级嵌套回复、取消回复、点赞/取消点赞、请求互斥、失败保留草稿、列表错误与空态区分。
- 成功发送后采用服务端数据；后续读取失败单独提示，避免误认为发送失败而重复发表。
- 后端读取可选访客头并返回 `liked`；个人状态不使用共享缓存。SSR 输出公共评论，挂载后取回设备点赞状态。
- 后端拒绝空白/超长内容、越界/跨文章父评论、超深回复和归档文章评论；公开接口无法指定 `isOwner`。
- 评论创建锁定文章，点赞切换锁定评论，以事务保护计数；文章旧种子计数在发表评论时按真实总数校准。
- 游客身份在客户端挂载时从本地恢复；存储不可用时设备请求 ID 在当前会话内稳定。

## 浏览器与数据库证据

使用已连接的浏览器实际操作，未通过脚本替代页面点击。桌面测试采用正常视口及 1440×1000，移动测试采用 390×844，结束时恢复正常视口。

| 验收项 | 结果及证据 |
| --- | --- |
| 首页到文章客户端导航 | 首页显示数据库浏览数 1025 及更新后的评论数；进入详情显示真实评论树 |
| SSR 与刷新 | 直接读取 HTML 确认评论文本和数量来自数据库；浏览器刷新恢复三级评论树 |
| 游客身份 | 首次提交打开身份弹窗，确认后发表；后续刷新与主题切换不再重复要求身份 |
| 评论、回复、取消回复 | 浏览器创建根评论及深度 1、2 回复；取消回复后 textarea 草稿仍在 |
| 深度展示 | 第三层显示“已到最深回复层级”，不提供第四层回复入口 |
| 点赞持久化 | 点赞后按钮为 pressed 且计数为 1；刷新仍为已点赞；取消后再次刷新为未点赞且计数 0 |
| 发送失败/读取失败 | 停止已核实的本地 API 子进程；发布失败保留原草稿，刷新评论另显示加载失败而非暂无评论 |
| 网络恢复/双击保护 | 恢复原 Nest 监听服务，重试加载并双击发布；数据库仅新增一条对应正文 |
| 三套主题 | Nexus、Aurora、Dock 桌面均发表成功；三套主题 390px 下输入及发表成功，Dock 移动回复与点赞成功 |
| 标签页回归 | 81 个本地书签正常显示，点击 AI 分类显示对应 10 个书签 |
| 闪念回归 | 最终按域配置下显示原博主本地闪念，避免全局 HTTP 导致空列表 |
| 并发计数 | 两次并发发表评论后计数一致；4 个访客并发点赞增加 4，再并发取消恢复原计数 |
| 访客隔离 | 一个测试访客查询自身 liked=true，另一个访客对同一评论读取 liked=false |
| 最终配置验证 | 独立文章 HTTP 开关下新增“联调测试：最终按域配置 HTTP 验收”，数据库确认存在 |

本轮保留文章 1 下 12 条“联调测试”评论（ID 5–16），均 `is_owner=false`。父子关联为 5→6→7、10→11；文章评论计数与实际总数一致。其余现有数据未清除。

真实 HTTP 校验另外覆盖：空白内容、1001 字超长、缺少访客头、伪造作者字段均返回 400；无效父评论和跨文章父评论返回 404；第四层返回 409 / 1003。
归档拒评和草稿不可见由后端业务回归测试覆盖，前端业务拒绝消息/草稿保留由控制器测试覆盖，没有为此修改现有文章状态。

## 已知限制与后续

- 搜索、RSS、相关推荐仍有 Mock；文章点赞/浏览前端接入不在本轮范围，已加入前端 todo。
- 闪念 HTTP 存在 `owner-001` 与数据库 `tixxin` 的身份差异，后续按域联调处理；本轮保留其原本地能力。
- 网络中断导致响应丢失时不能保证重试幂等，UI 提示先刷新确认。双击与请求期间重复操作已验证受保护。
- Dock 390px 导航链接缺少可访问名称，设置入口操作偶有无响应，作为主题导航待复核事项记录；未扩展本轮主题重构。
- ESLint 的 9 个 warning 位于未改动的 CodeBlock、CustomScrollbar、GalleryItem、LightBox、LinkCard。构建仍有 Browserslist 数据过期、依赖弃用、动态导入/源码映射提示，均未阻止构建。
- 开发热更新期间曾出现一次 Vue transition 异常，完整重载后本轮评论操作未复现；故障注入产生的连接失败日志符合预期。
- `/ready` 目前为静态健康信息，本轮以真实文章/评论请求和 SQL 同时核实数据库可用。
