# 文档

TixXinBlog 的使用、开发与维护指南。项目介绍和快速开始见[根 README](../README.md)。文档中的命令以仓库当前版本为准，功能接口以源码及测试为核对入口。

| 文档                                  | 内容                                                     |
| ------------------------------------- | -------------------------------------------------------- |
| [本地开发与测试](development.md)      | 安装配置、迁移、服务启动、开发样本、构建隔离和正式验证   |
| [架构与代码入口](architecture.md)     | 工作区、前后端分层、数据与权限边界、关系及持久任务职责   |
| [内容与后台使用](content.md)          | 站点资料、写作发布、互动、图库/项目/友链、媒体和内容发现 |
| [API 契约](api.md)                    | 认证、响应、版本/幂等/内容上下文及主要业务接口           |
| [备份与恢复](backup-and-recovery.md)  | v9 内容包兼容、迁入预览、完整快照、独立恢复和数据切换    |
| [部署与版本切换](deployment.md)       | 固定镜像、HTTPS、索引配置、初始化、发布、回退和隔离演练  |

建议首次使用按“开发 → 内容 → 备份 → 部署”阅读。扩展接口前核对 API 与架构，维护外部投递前核对运行任务的开关和不确定结果处理。

当前书签保存在浏览器 LocalStorage；访客注册、书签云同步、公开友链申请和访客邮件订阅未开放。HTTP 启动不执行迁移、seed、清库或持续任务，SMTP、自动备份与 worker 默认关闭。

文档保持长期有效的操作与契约。截图、运行日志、性能采样、临时脚本和原始测试报告使用本机忽略目录，具体约定见[开发指南](development.md#验证入口)。
