# 运营工作台

`/admin` 按真实服务端查询组织日常创作与互动处理，不拉取全部业务列表拼接统计。

- 六类草稿：文章、闪念、朋友圈、图库、项目、友链。软删除内容排除；闪念草稿排除归档项，项目进展不影响发布状态。
- 五类互动待办：文章评论审核、朋友圈评论审核、留言审核、文章评论待回复、留言待回复。朋友圈和闪念没有可靠的父回复关系，不制造待回复统计；闪念没有审核状态，不制造审核待办。
- 文章待回复是公开未删文章中可见的游客根评论、没有可见博主直接回复。留言待回复是公开未删游客根留言、没有公开未删博主直接回复。已读通知不影响这些业务口径。
- 最近编辑由六域各自限量再在数据库合并为最近12项，排除软删除项；固定次级排序，入口直达实际编辑页。
- 数量链接携带对应状态/待回复过滤；闪念支持 `?create=true`、`?edit=编号` 与 URL 分页筛选。朋友圈跨动态审核入口为 `/admin/moment-comments?status=pending`。
- 统计和最近编辑分区分别返回不可用状态，请求失败不会显示虚假零值。真正空列表与失败分开处理，提供重试。

本批后端 `overview-integration.mjs` 验证六域草稿、五类待办与对应列表计数、留言分页/回复隐藏删除、朋友圈审核冲突/动态删除排除和稳定最近编辑；前后端定向单测与静态检查通过。断点、主题、三浏览器及运行信息区域仍随本轮后续批次验收，未将此子批次计为七项整体完成。
