# 站点定位与首批内容

本轮用户仅确认公开称呼 `tixxin`。默认定位为技术写作，项目和图库作为辅助内容，生活保留独立入口。技能熟练度、工作/教育经历、兴趣、书单、联系方式和个人摄影经历均未获确认，不为填满页面而补造。

## 资料盘点与维护

| 位置                                 | 核实来源                                               | 本轮处理                                                         |
| ------------------------------------ | ------------------------------------------------------ | ---------------------------------------------------------------- |
| 姓名                                 | 用户本轮回复 `tixxin`                                  | 使用已确认大小写                                                 |
| 首页/侧栏/关于页姓名简介             | `/site`、站点设置初始迁移                              | 统一维护于 `/admin/site`，关于页不再复制维护                     |
| 原职位、头像、Twitter、邮箱          | 初始迁移直接写入，日常库版本为 0，未找到用户确认       | 显式资料整理命令只对未编辑初始值移除；保留历史，已编辑配置跳过   |
| 原关于页经历、技能百分比、兴趣和书单 | `features/about/mock.ts` 的界面示例                    | 移除运行时导入与无引用示例文件；新资料默认隐藏                   |
| TixXinBlog 项目                      | 根与前后端 package.json、实际业务代码、Git origin      | 可作为事实准确的项目说明和技术草稿来源；不声称成果指标或任职经历 |
| 其他项目与生活记录                   | 内部 `development_fixture`、各域种子                   | 开发环境长期保留，不能直接当作用户的真实作品、经历搬入生产       |
| 图库照片                             | `seeders/gallery-assets/README.md`、外链种子与素材来源 | 保留第三方出处，未知设备/地点不填写，不宣称由博主拍摄            |
| 社交与友链                           | 社交为个人事实，友链为网站目录                         | 个人联系方式等待确认；技术文档目录不等同于已互链或博主参与开发   |

关于页维护在 `/admin/site`：详细介绍、经历、技能、兴趣、书单按栏目与条目顺序展示；栏目和条目分别显隐，空名称条目不公开。服务端公共接口剔除隐藏资料，后台与历史保留完整资料。没有数字化技能熟练度默认值。保存使用原站点版本和媒体历史保护；旧客户端或 v1–v7 内容包未提供 about 时保留目标关于页。

全新安装也采用安全缺省：正式迁移 `20260911225000_sanitize_initial_profile` 仅匹配完整未编辑的旧默认及原始历史，生成安全版本1（空职位/社交、抽象头像、空隐藏关于页），保留原版本0。手工修改、已有新版本或不匹配的历史均跳过；回退迁移不自动重新公开旧占位资料。日常库原本已整理为版本1且有介绍，本次迁移完整保留，未覆盖配置。生产迁移镜像已在独立PG16回放33项并核对安全缺省与两份历史。

```sh
corepack pnpm db:dev prepare-profile
corepack pnpm db:dev prepare-profile --apply --confirm tixxin_blog
```

命令仅允许本机非生产、显式确认、迁移与结构一致的目标；实际修改前完整备份。只匹配精确未编辑的旧初始版本 0 或下述安全初始版本 1，版本竞争由真实服务拒绝，重复执行不再修改。若资料已编辑，结果 `eligible=false`，请直接在后台按确认事实维护，工具不会猜测或覆盖。

工具同时支持上述精确安全初始版本1，但必须与该迁移的历史原因及完整值匹配；备份之后在写锁内重新核对，手工SQL未递增版本的修改也会保留。

## 可审阅的正文

首页介绍：**技术笔记、项目实践与生活记录。** 关于页介绍：这里主要记录 Web 技术实践，整理 TixXinBlog 的实现与维护过程。项目用于介绍具体实现，图库用于整理图片与来源，生活记录保留独立入口。

代表项目说明：TixXinBlog 是基于 Nuxt 4、Vue 3、TypeScript、NestJS、MikroORM 和 PostgreSQL 的个人博客。文章、闪念、朋友圈、留言、图库、项目和友链走真实业务接口；三套布局由主题契约组织。后台提供版本保护、媒体管理、内容包迁入和完整备份恢复。书签当前仍保存在当前浏览器，友链公开申请尚未开放。描述不包含访问量、用户规模或商业成绩。

首批技术草稿围绕实际代码组织：数据与页面职责、版本冲突与恢复、内容包和完整备份的区别。新增草稿保持草稿状态，事实来源用仓库相对文件名列在正文；没有执行对外发布。开发样本与真实内容候选使用独立登记，正式运营前由博主审阅选择。
