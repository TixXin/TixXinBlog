# 内容发现与关联阅读

搜索入口为顶部搜索框和 `/search`。范围明确为文章、项目、友链、图库、闪念、朋友圈；不包含管理员私有信息或本机书签。

- 全部类型各预览3项并显示各域真实总数；它是分类型预览，不宣称统一相关排名。
- 选择某一类型后每页10项，`q/type/page` 保存在地址栏，返回可恢复同一筛选和页码。
- 文章保留标题、摘要、正文和标签检索；各域中文及 `%`、`_`、反斜杠按字面查询，次级编号使分页稳定。
- 来源失败时该域总数为未知，其他成功结果保留；快速输入、切换类型和关闭弹窗会取消旧请求，不让迟到响应覆盖当前查询。
- 图库使用 `/gallery?photo=编号`，项目使用 `/projects?project=编号`，闪念和朋友圈进入原详情地址。项目编号入口不依赖标题，缺失或撤回仅影响详情区域；文章地址、重定向、RSS和sitemap保持原契约。

文章、项目与图库表单可以查找并选择关联内容，最多12项，按上移/下移维护顺序。关系从当前内容指向目标，不自动创建反向关系；自关联拒绝，重复条目归一。管理端可看到缺失或删除标记，原失效关系可以保留或解除，新失效目标不能加入。公开详情只投影当前允许公开的目标，隐藏与草稿标题不泄露。

文章侧栏自动相关文章优先同专栏与共同标签，再用发布日期和编号排序；正文后的关联阅读由博主明确维护。已有文章置顶和友链推荐仍属于各自编辑设置，不制造热门分数、外部Star或访问成绩。

新增关系随来源内容版本保存；文章修订和编辑恢复副本保留原始有序关系，旧快照缺省空数组。关系与媒体引用分开：增加阅读关系不会增加图片使用次数。迁入编号映射、旧包兼容、失效目标省略计数与完整恢复见 [备份契约](backup-and-recovery.md)。素材及评论头像的使用位置见 [媒体整理](media-organization.md)。

`discovery-search-integration.mjs`、`content-relations-integration.mjs` 与 `content-relations-backup-integration.mjs` 验证公开状态、真实分页、权限、版本、循环/跨域映射、跳过复制及回滚；相关三浏览器搜索15组合、三域关联3组合已通过。日常 `writing-v1` 展示长文、项目与图库互相继续浏览，具体数量与来源见 [开发数据](development-data-catalog.md)。
