# 图库外链与后台工作区交付验收

验收日期：2026-09-11。本轮范围为图库外部图片 URL 和管理后台布局/操作体验两项扩展。实现、日常样本、维护兼容、隔离验证、只读日常验收及资源清理已完成；不包含推送、部署或对外发布。

## 来源模型与维护兼容

`gallery_photo.media_id` 与新增 `external_url` 恰好有一个有效值。正式迁移 `20260911190000_add_gallery_external_source` 原地扩展旧表，保留作品主键、媒体关联、状态和版本；无需逐条重新保存。服务端拒绝双填、全空、危险协议、凭据、空白/控制字符和不完整地址。受管媒体路径即使被域名或编码包装，也不能作为外链绕过引用管理。

外链原始大小写、重复参数与编码不重写。媒体切换为外链释放该作品引用，反向切换重建引用；其他业务和历史引用继续保护同一媒体。外链不创建媒体资产，不删除远程文件。草稿和撤回的受管作品沿用原有引用保护。

内容包显式升级为 v7，图库记录增加互斥的可空 `mediaId/externalUrl`，兼容 v1–v6；旧版本夹带外链新字段明确拒绝。跳过/复制、草稿状态、媒体映射、预览变更确认、事务回滚和同票据幂等均保留。完整恢复校验新旧来源结构、全部表摘要和真实媒体引用，生产镜像进一步验证恢复后外链读取、旧授权/旧内容上下文拒绝与新上下文保存。

## 用户操作行为

编辑页在媒体库图片与外部图片 URL 间切换；两套未提交输入保留，实际请求仅提交选中来源。恢复副本升级为 v2并读取旧 v1，保留原请求标识、账号与内容库隔离。保存失败、未知提交、迟到响应和版本冲突继续保留输入；另一来源仍有未提交输入时不会将其冒充为服务器已保存内容。

地址校验和图片预览分别反馈。合法地址即使当前加载失败也能保存；预览提示网络故障、防盗链、地址失效或浏览器策略等可能原因，不声称知道浏览器未暴露的具体原因。未知尺寸先按3:2占位，浏览器成功加载后使用真实比例，不写入伪造宽高、格式或EXIF。公开筛选、分页、统计和深链定位不依赖图片加载是否成功；灯箱保留重试、键盘切换、关闭与焦点返回。

沿用原生图片和现有安全策略，没有新增服务器抓取、优化代理、探活、转存或 EXIF 提取。HTTP(S)格式可保存；现有 CSP 仅允许同源/data/HTTPS图片，HTTP外链可能被CSP或混合内容规则阻止，推荐HTTPS。未扩大CSP或网关访问范围。
