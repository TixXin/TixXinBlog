# 媒体检索与素材说明

独立媒体库和文章、图库、项目等表单里的媒体选择器共用检索与说明维护。搜索支持文件名、替代文本、素材说明以及完整媒体 UUID；正文采用字面子串检索，`%`、`_` 与反斜杠不是通配符。

## 使用方法与口径

- “媒体构图”按真实宽高分为横向、竖向和方形，依据规范化后的图片尺寸，不推断照片题材。
- “媒体使用状态”查询真实媒体引用索引。“已使用”包含当前内容、草稿、归档、评论和历史修订；没有当前公开引用但仍被历史版本使用的图片也算已使用。
- 搜索、构图、使用状态和回收状态可以组合，服务端先筛选再分页。列表和总数共用过滤条件，按上传时间、UUID 倒序稳定排序；前端不会下载全量资源来筛选。
- 替代文本描述画面，素材说明独立记录出处、使用说明等信息，最多 1,000 字符。两者分别保存，更新其中一个字段不会顺带覆盖另一个。
- 有未保存的替代文本或素材说明时，禁止翻页和选择图片；关闭选择器或离开工作区继续沿用输入保护，刷新和关闭页面也会提示。素材资料必须手动保存，确认放弃后不会假称仍有恢复副本。账号或内容库变化后停止旧操作并保留原输入，旧响应不会覆盖新库的数据。
- “查看引用”继续返回真实引用数量及历史版本。文章、图库、项目、友链、朋友圈和闪念使用已有正式管理入口；文章评论进入对应 `commentId` 上下文。旧朋友圈 `?edit=` 地址继续由原页面兼容处理。

上传协议和同一上传标识的重试行为保持原样；上传后的素材说明可以在列表中维护。说明不参与引用计数，也不会改变原图尺寸、原图加载需求或文件清理条件。回收资源保留说明，恢复后可以继续编辑。公开图片接口仍只返回图片字节；说明查询与维护属于管理员接口。

## 实际检查与交付边界

修改前在 Nuxt 测试环境挂载真实 `MediaLibrary` 与 `useMediaLibrary`，以选择器模式读取资源：显示原有替代文本、尺寸和分页，没有素材说明、构图及使用状态控件。对应实际组件交互测试先失败，新增能力后通过。代码核查还确认闪念引用原本只能到整个列表，朋友圈引用经过旧编辑地址重定向；本批将普通内容引用改为准确编号入口，保留旧地址兼容。

朋友圈评论头像与通知可使用 `/admin/moments?comments=<momentId>&commentId=<commentId>`，闪念评论使用 `/admin/flashes?comments=<flashId>&commentId=<commentId>`。页面打开对应评论面板并聚焦、标出目标；省略 `commentId` 时打开所属内容的评论面板。朋友圈通过只读管理员接口 `/admin/moments/:id/comments/:commentId/location` 按真实时间/编号顺序定位每页 15 条的目标页，不逐页拉取全量评论。隐藏、待审核评论保留管理可见性；评论删除、来源不匹配或不存在时显示明确反馈。原有编辑深链保持兼容，未发送回复仍受原有保护。

字段迁移为 `20260911224000_add_media_description.ts`：增加非空 `description`，旧资源缺省空字符串。回退应用版本时保留该列及已填写说明。PATCH 未传字段保持原值，显式空字符串用于清空；`null` 与超长说明会被拒绝。内容包编号映射、旧包导入保留规则、完整备份恢复和日常样本由统一维护批次接入；本文件不将这些工作提前视为完成。

## 验证入口

- 前端单测：`mediaOrganization.test.ts`、`mediaLibraryOwnership.test.ts`、`mediaUploadOwnership.test.ts`，覆盖实际选择器、组合查询、分页、说明保存失败与迟到响应、换账号及内容库保护。
- 后端单测：`media-organization.spec.ts`，覆盖字段校验、单字段更新和正式引用地址。
- 评论深链单测：`adminCommentDeepLinks.test.ts`、`moment-comment-location.spec.ts`，覆盖第三页定位、缺失反馈、迟到响应与未发送回复保护；原有闪念入口及动态身份回归继续执行。
- 隔离 API：`media-integration.mjs` 增加横、竖、方图、历史引用筛选、组合条件、三页去重、说明保留与回收恢复；`moment-integration.mjs` 使用正式动态编辑地址。
- 隔离浏览器：`media-organization.spec.ts` 覆盖 320、390、1440px 的说明检索、真实组合筛选、引用进入编辑页以及选择器未保存保护。图片来自该隔离场景生成的彩色构图素材，不写日常数据库。
- `admin-comment-deeplinks.spec.ts` 检查评论跨页焦点、隐藏评论仍可管理、刷新及删除后的准确反馈。

截图和运行报告由现有测试输出保留在 `.playwright-mcp/` 或 `.artifacts/`；日常媒体、开发账号、备份与样本不会被这些测试清理。完整构建、接口与浏览器集成验证由统一交付流程执行。
