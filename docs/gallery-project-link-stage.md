## 交付约束

- 图库作品与媒体文件分离，宽高和格式来自媒体；拍摄日期缺省不冒用创建时间。
- 发布状态独立于项目进展、友链推荐；公开接口过滤非公开内容。媒体沿用既有文件访问边界。
- 管理操作复用认证、内容上下文、审计、提交去重、版本冲突和媒体引用锁。
- 内容包在当前 v3 基础上显式演进，保留旧版本契约；导入保持非公开。
- 日常库写入前确认本机目标并备份，只增量补齐；自动验证使用独立数据库、媒体和账号。
- 原始日志和截图只写入 `.artifacts/` 或 `.playwright-mcp/`，本文件记录实际文字结论。
