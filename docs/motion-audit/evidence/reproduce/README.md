# 本轮实验脚本

这些文件是本轮实际执行脚本的快照，不包含密码或token值。脚本读取本轮临时state文件中的隔离地址/凭据；清理后state已标closed，因此不能直接用已结束的实例重跑。

重新实验时应从当前源码建立新的独立副本、独立Nuxt/Vite生成目录与随机数据库，使用仓库createBrowserTestApp安全流程。修改prepare/serve中的本机根路径和新副本目录，并在启动服务时保持stdin可用（PTY）或提供明确的本机停止通道。不能将写入脚本指向日常开发服务。

audit-runner.mjs的suite参数见各if分支。observed表示采集完成，不是缺陷测试通过。所有fixture数据、故障拦截和A/B改动仅用于隔离实验，不能当作正式产品补丁。
