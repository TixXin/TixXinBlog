## 具体行为

- `admin.vue` 外壳占据动态视口，顶部栏与桌面导航保留在视口中；`.admin-main` 是唯一主内容滚动区。内容内部保留原有必要表格、弹窗及编辑器滚动，不以整个页面的横向溢出隐藏问题。
- 桌面导航在自己的可用高度内滚动；品牌与返回博客入口固定可用。活动项只调整最近的导航滚动容器，不再调用会影响外层页面的 `scrollIntoView`。链接明确可通过 Tab 逐项访问。
- ≤760px 使用 `ContextDrawer` 和既有 `useModalFocus`：支持 Escape、焦点约束与归还、背景隔离和滚动锁。导航成功后关闭；到761px及以上自动清理抽屉。未保存离开被拒绝时不擅自改变当前编辑状态。
- `AdminActionBar` 统一文章、图库、项目、友链、朋友圈、站点、器材和友链须知的操作容器。桌面文章操作吸顶，其他表单吸底；窄屏及低高度视口使用正常文档流，避免操作栏占据过多空间。顶部“表单操作”可直接定位并聚焦操作区，滚动留白保护键盘定位。
- `AdminBackLink` 返回当前标签页记住的模块列表地址，保留搜索、状态与分页。`useAdminWorkspace` 按完整查询地址保留滚动位置，在异步内容到达后恢复；其他后台入口使用同一逻辑。此位置记录属于当前应用会话，完整关闭/重新载入应用不承诺保留像素位置；URL中的筛选和页码仍有效。
- 活动导航根据模块路径匹配，进入新建、编辑或设置子页仍标记所属模块。所有操作继续使用原来的事件、请求、禁用条件及反馈，没有绕过恢复或版本确认。

## 验收范围

`admin-workspace.spec.ts` 覆盖桌面独立滚动、15项导航逐项 Tab、320/390/760/761px、Escape与焦点返回、路由/跨断点清理、列表返回、三主题全部后台入口。320/390px另巡检管理概览、文章列表/编辑、图库列表/编辑、项目列表/编辑、友链列表/编辑、媒体、站点及维护页面，并检查主内容没有横向溢出。

共享表单回归沿用文章会话恢复、版本冲突、草稿自动保存、媒体选择、批量弹窗、站点配置冲突及历史恢复，以及项目/友链/朋友圈创建、修改、恢复和提交核查。详细结果与未覆盖环境见本轮交付记录。

浏览器截图不能证明所有辅助技术合规。本轮实际检查键盘、焦点、减少动态效果及响应式重排；真机触控、系统级屏幕阅读器及操作系统级缩放另列为环境边界。内置浏览器的缩放快捷键未改变 `innerWidth`、`devicePixelRatio` 或 `visualViewport.scale`，因此不把这次按键声称为真实浏览器缩放验收。
