# 内容与后台使用

后台入口为 `/admin`。使用前完成[管理员初始化](deployment.md#初始化管理员)，公开页面与管理页面共用真实数据。站点资料、内容发布、通知已读和任务启用分别保存，不因执行其中一项而自动改变其他状态。

## 站点资料

在 `/admin/site` 维护站点名称、简介、头像、社交方式、公告及关于页。关于页支持介绍、可选栏目、栏目和条目的排序与显隐；未填写或隐藏的资料不会出现在公共 `/site` 响应中。

填写可核实的个人信息，使用有权发布的图片；保留来源与许可。新安装不应把示例经历、默认职位或第三方照片当作博主事实。开发样本用于验证功能，不自动成为站点的真实作品。

同一页面的“导航与页脚”编辑区维护：

- 导航：内置模块（主页、归档、项目、画廊、闪念、友链、留言、平台订阅费、关于、提示词、标签页）的显隐与顺序，以及最多 4 个 http(s) 外链（可选新窗口）。首页始终显示；隐藏只让模块从三套主题与移动导航中消失，页面地址仍可访问，sitemap 收录不受影响。排序使用上移/下移按钮，键盘可操作。
- 页脚链接：最多 8 个，站内路径（如 `/about`）或 http(s) 地址；`/rss.xml` 等服务端文件和站外地址以原生链接打开。
- 每日一言：最多 30 条、每条 ≤120 字且不重复，页面加载时随机展示一条；清空后不展示一言卡片。
- 备案号与版权：填写 ICP 备案号后页脚显示，链接留空时指向工信部备案查询；版权文案留空使用 `© 年份 站点名. All rights reserved.`，自定义时可用 `{year}`、`{siteName}` 占位。Powered by 为框架声明，保持代码内置。

升级前未保存过这些字段的站点按缺省值展示，缺省值等于此前代码内置的导航、页脚链接与一言，外观不变。编辑区支持 Ctrl/⌘+S 保存，输入错误就地提示，保存时以服务端校验为准。

配置保存带版本保护，并保留历史。恢复旧版本或遇到冲突时，预览能够核对完整资料，包括隐藏字段；旧客户端或旧内容包未提供的新字段保持目标值。

## 写作、发布与恢复

| 业务   | 公开入口                         | 管理入口与状态                                             |
| ------ | -------------------------------- | ---------------------------------------------------------- |
| 文章   | `/`、`/archive`、`/articles/:id` | `/admin/posts`；草稿、发布、归档及独立回收状态             |
| 闪念   | `/flash`、`/flash/:id`           | `/admin/flashes`；草稿/发布与归档行为按表单分别处理        |
| 朋友圈 | `/moments`                       | `/admin/moments`；`draft/published/archived`、置顶与评论   |
| 留言   | `/guestbook`                     | `/admin/guestbook`；`published/pending/hidden`、回复与置顶 |
| 图库   | `/gallery`                       | `/admin/gallery`；`draft/published/withdrawn`              |
| 项目   | `/projects`                      | `/admin/projects`；发布状态与项目进展分别维护              |
| 友链   | `/links`                         | `/admin/links`；`draft/published/withdrawn` 与独立推荐状态 |
| 提示词 | `/prompts`                       | 登录博主页内添加和编辑；`draft/published`                  |
| 订阅费 | `/subscriptions`                 | `/admin/subscriptions`；发布状态与订阅活跃状态分别维护     |
| 书签   | `/tabs`                          | 当前浏览器存储，使用页面提供的导入/导出入口                |

文章编辑器支持 Markdown、封面、专栏、标签、发布检查和历史修订。自定义地址、历史地址重定向、canonical、robots 与 sitemap 由正式发布状态控制；撤回内容不应继续出现在公开查询或订阅中。

“正文章节”从当前 Markdown 计算标题和源码行号，重复标题可区分。先选择再定位，光标和正文滚动到目标行；代码块中的伪标题不会成为章节。定位不重写正文、不清除撤销历史，输入法合成期间不移动光标。

保存期间的新输入、刷新恢复、会话过期与版本冲突分别处理。发生未知创建结果时，先核查原提交；不要更换标识重建。恢复副本不等于已保存，离开前按界面提示保存、恢复或放弃。部分恢复状态属于当前标签页或账号，不承诺跨设备同步。

后台桌面导航和主内容独立滚动，窄屏使用抽屉；Escape 关闭并归还焦点。返回列表保留 URL 中的筛选和页码；当前会话内还可恢复滚动位置，完整关闭应用后不承诺恢复像素位置。

## 朋友圈与留言

朋友圈支持正文、图片、话题、日期筛选、文章关系、置顶与真实互动。公开列表默认置顶优先；订阅按时间读取最新公开内容。图片、话题、日历和回顾从实际公开记录聚合，不根据样本静态填写数量。

访客评论遵循站点审核策略，博主回复身份由认证和站点配置确定。未通过审核的内容仅在允许的身份范围内反馈。隐藏、归档或删除后，公开聚合与引用同步遵循可见性规则。

留言可按作者、正文或日期筛选，聊天式与论坛式展示使用同一业务数据。Ctrl/Command+Enter 发送，失败保留正文并沿用原提交标识重试。回复只引用公开留言；父留言隐藏或删除后，回复仍可存在，但不会泄露原作者或正文。

管理端可回复、审核、隐藏、置顶和删除留言；公开置顶最多一条。回应数量来自实际记录。系统没有在线状态、已读回执或实时推送，通知已读也不替代回复。

## 图库、项目和友链

图库作品使用受管图片或外部图片地址，两种来源必须恰好选一。切换来源仍编辑同一作品。外链由浏览器直接显示，推荐 HTTPS；加载失败可能来自网络、防盗链或浏览器策略，不会自动删除作品。服务端不抓取远程文件、不生成 EXIF 或虚构尺寸。

拍摄日期、地点和设备是可选资料，未知时留空。上传文件不会自动创建作品，创建作品也不会自动公开。`/admin/gallery/settings` 的器材介绍是独立配置，与作品统计分别维护。

项目的 `progress` 为 `active`（维护中）、`dev`（开发中）或 `archived`（已归档）；`status` 决定是否公开。已归档的项目仍可公开，开发中的项目也可保留草稿。技术标签表达项目采用的技术，不代表代码语言占比；外部链接可按源码、演示、文档和下载用途设置，缺少时留空，不使用占位跳转。

友链由博主管理，推荐不表示已经验证互链。站点地址按完整 HTTP(S) URL 校验，同域不同路径可以分别登记；普通新建和改址不允许与未删除记录重复。内容包复制可保留同址草稿，但同一地址最多有一条公开记录。Logo 可为空、受管媒体或外部 HTTPS 图片，受管与外部来源互斥。交流规则在 `/admin/links/settings` 独立维护；公开申请、自动探活和站点抓取未开放。

## 图片提示词

`/prompts` 的灵感图鉴以图片展示作品，支持正文搜索、模型与风格标签筛选和分页。打开作品可以阅读完整提示词、可选负面提示词、创作笔记与来源，复制文本或分享 `/prompts?prompt=<编号>` 链接。未标注模型时显示明确缺省信息，不推测生成模型。图片按收录顺序进入瀑布流，详情可用按钮或左右方向键浏览当前页；正在选择文本或编辑链接时不触发切图。公开分享链接在首屏 HTML 中提供对应作品的标题和图片，草稿与编辑地址不参与索引。

博主登录后，点击「分享灵感」添加内容，卡片或详情中的编辑入口修改已有内容；「我的草稿」仅博主可见。新内容可以保存草稿或发布，已公开内容也可收回草稿。保存结果未知时沿用原提交标识核查；版本冲突保留当前输入，明确合并后再保存。未保存输入保存在当前会话的恢复副本中，不等于已经发布。`/prompts?edit=new` 新建，`/prompts?edit=<编号>` 继续编辑；浏览器后退或切换编辑对象会检查未保存输入。Cmd/Ctrl+S 按当前草稿或公开状态保存，不隐式发布。新建确认保存后，后续输入副本随真实编号保存。身份或内容库变化时锁定并遮蔽表单，内存输入仍保留；恢复原身份后再继续。内容库变化与版本冲突分别处理，前者不能合并到新库的同编号内容。

效果图可从媒体库选择、上传或填写完整 HTTP(S) 图片直链，受管媒体和外链必须恰好选一。服务端不抓取外链，外链宽高未知时不虚构尺寸。提示词以纯文本显示，不执行其中代码或 HTML；来源链接与正文分别保存。

开发样本 `prompts-v1` 包含带完整生成输入的原创图，以及明确注明来源的摄影参考练习；参考照片不声称是提示词的生成结果。通过 `db:dev seed-data --dataset prompts-v1` 预览后，按开发指南确认与备份再补充到本机库。内容包导出包含提示词，迁入统一生成草稿；完整备份保留版本与媒体引用。

## 平台订阅费

`/subscriptions` 展示博主公开的平台费用，按分类、币种、订阅状态和名称筛选。它与文章 RSS/邮件订阅不同，不执行支付、自动扣款或通知投递。博主在 `/admin/subscriptions` 新增、编辑、发布、撤回、软删除与排序，也可在公开页快捷编辑。修改价格、币种或周期时自动追加新的价格快照；历史只读，普通文字编辑不会生成变价事件。管理备注不会出现在公开接口。

金额按原币种独立统计，JPY 按整数显示；月/季/年付分别按 12/4/1 倍计算年化，月均先汇总精确值再舍入。只有已经开始的活跃持续订阅进入当前预算，暂停、取消、试用和过期不计入；一次性和买断单独显示记录金额。图表中的未来 12 个月续费是基于日期、状态和价格的预测，不代表已支付支出；未知日期不预测，逾期明确展示。

官网图标可由博主管理操作触发获取；优先显示选择的受管图标，随后是自动 favicon，失败则显示 Lucide 图标。服务器只访问固定供应商，缓存可重新生成。不要在公开描述填写私人账单资料，需要保留的私密说明使用管理备注。

“我的订阅”独立保存在当前浏览器，可新增、编辑、删除并查看自己的统计和价格历史；清理浏览器数据会丢失，不提供账号或云同步，也不会因管理员登录而上传成博主记录。存储失败、损坏数据与跨标签页编辑冲突需要按页面提示处理，不能把未落盘输入当作已保存。

开发样本使用 `subscription-v1` 稳定归属，金额仅为功能代表值，不是博主真实购买记录或平台当前报价。内容包 v11 保留博主订阅和完整价格历史，迁入创建草稿；完整备份包含管理备注、提交身份、删除状态及图标关系。

## 媒体与引用

`/admin/media` 与表单中的媒体选择器共用服务端搜索、构图、使用状态和回收筛选。构图来自实际宽高；“已使用”包括当前内容、草稿、归档、评论及历史修订。没有公开引用并不等于可以回收。

替代文本描述画面，素材说明可记录出处或用途，两者独立保存。存在未保存资料时，先保存或明确放弃，再翻页、选图或离开；这些资料使用手动保存，不假称存在自动恢复副本。

“查看引用”显示真实业务与历史引用，可跳转到相应编辑页或评论位置。替换、删除某条内容只释放其自身引用；其他引用继续保护媒体。受管文件会转换为 WebP，运行媒体目录不保存原始上传文件。

独立媒体页支持勾选当前页的可用资源并批量移入回收；翻页、筛选或重新加载会清空选择。确认后逐项检查引用，只有没有引用的资源才尝试回收，服务端执行时还会重新校验。结果逐项列出成功、引用位置或失败原因，单项失败不影响其余资源；账号或内容库变化时停止后续操作。回收保留文件，可在回收资源中恢复；删除响应失败时先重新读取核对状态，再决定是否重试。表单中的媒体选择器不提供批量回收。

持有有效受管媒体 URL 的访问者仍可读取该文件。草稿、撤回或隐藏业务内容不会使文件自动变为私有；不要用公开媒体库存储需要访问控制的附件。

## 搜索、关联与订阅

搜索覆盖文章、项目、友链、图库、闪念、朋友圈，排除私有内容和本机书签。全部类型显示分域预览和实际总数，单类型分页；地址栏保留 `q/type/page`。来源失败时保留其他成功结果并标明不可用，不显示假零总数。

图库分享可使用 `/gallery?photo=<编号>`，项目使用 `/projects?project=<编号>`。编号对应真实内容，不依赖标题；目标撤回或不存在时提供明确反馈。

文章、项目和图库可维护最多 12 条有向、有序关联。关联不自动双向生成；自关联拒绝，重复目标归一。原失效关系可保留或解除，新失效目标不能加入；公开详情只展示仍可公开的目标。文章侧栏的自动相关文章按同专栏、共同标签和时间规则排序，与人工关联分别维护。

文章订阅、朋友圈 `/moments.xml` 和 `/api/moments.json` 读取真实公开 API 与运行时站点地址。朋友圈订阅按时间输出最新记录，省略私人身份和评论；上游错误返回错误状态，不以 Mock 填充。sitemap 和 robots 的生产/预发布配置见[部署指南](deployment.md)。

## 互动与维护

`/admin` 汇总真实草稿、审核与待回复事项；数量链接进入对应筛选。文章和留言的待回复依据可见游客根记录及博主直接回复，不把其他没有可靠回复关系的领域算作待回复。站内通知已读与业务处理状态独立。

内容迁入通过 `/admin/maintenance` 的预览和确认执行，导入后按各域草稿/待审规则复核；完整备份用于保留数据库和媒体。详见[备份与恢复](backup-and-recovery.md)。运行队列、邮件与自动备份见[运行维护](operations.md)。
