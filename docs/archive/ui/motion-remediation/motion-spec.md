# 当前动效规则

> 历史归档：原文来自 `docs/motion-remediation/motion-spec.md`，保留当时的设计、实施与验收事实。文中的阶段、版本、数量和“当前／下一步”不代表现状；现行入口见[文档导航](../../../README.md)。本机验收产物仍按原仓库相对路径留存。

本文记录本轮实现中的规则与预算，数值属于项目设计选择，不代表可访问性标准规定。

| 用途           | 当前实现                                                                                          | 减少动态效果及中断                                                                |
| -------------- | ------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------- |
| 普通交互反馈   | `--motion-fast`默认160ms，`--motion-normal`默认200ms；仅颜色、背景、边框、阴影、透明度和transform | CSS媒体查询取消补间；保留终态、焦点和状态文字                                     |
| 主内容导航     | 纵向150ms/8px、轻柔160ms/6px、淡入淡出140ms；进入ease-out、退出ease-in                            | 关闭/减少模式不创建动画；实例不因偏好切换重建；新导航取消旧任务                   |
| 侧栏离场       | 源节点和克隆共同归属可取消任务；400ms清理兜底                                                     | 取消守卫、失败、完成、偏好变化、卸载都恢复原visibility                            |
| 列表新增       | 200ms入场；25ms交错、最大150ms；仅可见新增项                                                      | 离屏、已有内容或减少模式直接done；结束、取消、超时、卸载只收尾一次                |
| 界面设置       | 遮罩180ms、面板200ms/8px；使用半透明遮罩                                                          | 取消CSS过渡，关闭恢复焦点与背景；无全屏背景模糊                                   |
| 颜色切换       | 渐变220ms、模糊240ms、圆形320ms；圆心取触发位置                                                   | 无动画、减少模式或无API时直接切色；旧事务无权清理新事务                           |
| 图片           | 完成加载后一次180ms透明度揭示；比例、错误与重试由ImageFrame管理                                   | 缓存已显示图片不重复隐藏；减少模式/离屏移除/卸载清理；错误保持占位                |
| Tooltip        | 默认出现延迟200ms、共同悬停离开宽限140ms；长文字按视口换行                                        | Esc关闭且不会在同次悬停/聚焦中立即重开；关闭移除监听和描述关联                    |
| 阅读与滚动     | 阅读进度用scaleX，必要插值80ms；目录/j/k/t/回顶使用实际滚动根                                     | 减少模式即时定位；新请求、用户滚轮/触摸/按键中断程序滚动                          |
| Aurora背景     | 默认静态，手动播放8秒轮换；下一图加载成功后800ms交叉淡入                                          | 减少模式、Hero离屏、非主页、文档隐藏、卸载停止计时器及未完成图片                  |
| 首屏与主题加载 | 根据真实ready/pending/error更新；取消800ms等人为等待                                              | 首屏ready后的淡出层不拦截指针；可选主题失败不阻断当前页面；关键错误有原生刷新入口 |

认证表单的高度适配等局部尺寸过渡仍按组件用途保留；业务状态不依赖结束事件才更新。禁止用全局极短时长假装关闭动画，禁止`transition: all`引入滚动条、字体或尺寸的意外插值。

页面视觉动效由`usePageMotion`管理，NuxtPage的实例和异步渲染生命周期保持独立。退出副本去除ID并设为inert/aria-hidden；不得接受交互或进入可访问树。颜色、滚动和元素入场分别有自己的所有者、版本和清理句柄。

页面初始化读取由`usePageRequestScope`持有，销毁时取消，await之后必须检查所有者是否仍活动。默认布局只消费带专用标记的页面取消，真实请求和渲染错误仍交给正常错误边界。文章详情及补充信息在同一个AsyncData任务中读取；评论的初始读取可取消，已有评论控制器的提交、草稿和重试保持应用会话级生命周期。

焦点区分取消与导航：取消回到稳定入口，成功导航交给目标内容。应用级指针入口记录兼容点击按钮不自动聚焦的浏览器；键盘输入清除旧指针记录，业务主动移焦优先。嵌套弹层只关闭顶层，释放时还原背景inert、aria-hidden及滚动锁。

主题客户端缓存复用同一组件；SSR缓存按Nuxt请求隔离，避免热更新后继续渲染旧模板。CSS/SFC/布局/composable热更新及新SSR请求均需检查，而不只确认旧页面看起来更新。

性能验收使用固定负载、实际动画和重复样本。帧间隔、Paint、Style、Layout及长任务分别报告，不能以某个指标改善宣称所有指标改善。真实手机、实体Safari和后台可见性必须有相应环境证据。
