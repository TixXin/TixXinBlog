## 业务与维护结果

- 前台 `/projects` 和全站项目搜索均读取真实 API；后台 `/admin/projects`、`/new`、`/:id` 支持标题、介绍、可选封面、标签、链接、进展、发布、排序和删除。
- 进展 active/dev/archived 与发布 draft/published/withdrawn 独立。公开列表按排序值和编号稳定分页；技术分布按使用标签的公开项目数计算，不冒充代码语言分析，也不显示无来源 Star/Fork。
- 封面使用受管媒体，缺少封面或链接有明确缺省。服务端校验完整 HTTP(S) 地址与规范化后长度，保留路径大小写和参数；不执行外站抓取或仓库同步。
- requestId/hash、提交查询及删除墓碑保护未知创建结果，revision 防止旧版本覆盖；迟到保存、账号变化、恢复上下文和未保存输入由既有管理请求层与编辑器共同保护。
- 内容包升级 v5，projects 必填，v1–v4 契约冻结；导入保持草稿并保留进展、标签、链接、排序和日期。可选媒体映射、skip/copy、目标变化、事务回滚及真实断连后原票据核查均通过。
- 完整数据库和媒体恢复验证四种项目状态、封面关系、归属账本及长字段摘要；独立 Node24 Alpine 生产镜像实际读取恢复内容，旧令牌与旧内容上下文被拒绝，新登录和新上下文保存成功。
