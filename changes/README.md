# 更新日志片段

用户可感知的新增、变更、修复，以及数据库迁移、内容包版本、环境文件或编排变化，在同一个提交里于本目录新建一个片段文件，不直接改 `CHANGELOG.md`。多个会话各写各的文件，不会在同一段落里互相混改。

- 文件名用简短的英文短横线名，说明改了什么，例如 `rss-subscribe-modal.md`；一个功能或修复一个文件，后续补充可继续改同一文件。
- 内容按 `CHANGELOG.md` 的小节写，条目写在 `### 小节` 标题下：

  ```md
  ### 升级说明

  - 含一项数据库迁移：……

  ### 新增

  - ……
  ```

  小节按「升级说明、新增、变更、修复、移除、安全」排序，其他名称排在最后。迁移、内容包版本与兼容范围写在「升级说明」下。

- 纯测试、重构与内部文档不写片段。
- 发版时 `corepack pnpm release:prepare <版本>` 把全部片段合进「未发布」，整理成版本段落并删除用过的片段，随版本提交一起提交。
